 ✨Consumo de energia✨
 
 O objetivo deste programa é ajudar o úsuario a calcular o preço e a quantidade de energia mensal em KWH de seus aparelhos, utilizando os respectivos cálculos:

 ![Static Badge](https://img.shields.io/badge/tecnologia-Python-green)

 (Potencia * horas * 30)/1000 
 
 ((Potencia * horas * 30)/1000) * 0.75

 Para a execução adequada do código responda, sem por espaços na frente, o que se pede em cada pergunta.
